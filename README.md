# 🛡️ Labs.io — Network Security, Cyber Forensics & System Designs

Welcome to **Labs.io**, a hands-on engineering repository dedicated to network defense, packet analysis, cyber forensics, and distributed system architectures. Every lab here is built from scratch to test real-world vulnerabilities and automated mitigation strategies in isolated environments.

---

## 🎯 Objectives
* **Build from Scratch:** Move beyond high-level abstractions by dissecting raw network frames, state tables, and protocol behavior.
* **Simulate & Defend:** Replicate common LAN attacks in controlled multi-node sandboxes and engineer automated detection and response tools.
* **Reproducible Documentation:** Maintain clear setup guides and metrics so students, researchers, and engineers can replicate every experiment.

---

## 🛠️ Core Stack & Tools
* **Languages:** Python 3, Bash
* **Networking & Packet Analysis:** Scapy, Wireshark / tcpdump, `iproute2`, ARP / DHCP / STP protocols
* **Virtualization & Sandboxing:** Docker, Oracle VM VirtualBox, Ubuntu Linux
